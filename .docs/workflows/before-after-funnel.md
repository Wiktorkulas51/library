# Before After Funnel

## Goal

Turn a weak local-business site into a reusable redesign concept, then into a template and an upsell path.

## Inputs

- One weak site.
- One screenshot or screen recording of the current page.

## Output

- 3 to 5 visual directions in `9:16`.
- A selected direction.
- A template plan.
- An upsell plan for implementation or monthly care.

## Files

- `brief.md`
- `viz-01.md`
- `viz-02.md`
- `viz-03.md`
- `viz-04.md`
- `viz-05.md`
- `selected.md`
- `template-plan.md`
- `upsell-plan.md`

## Steps

1. Capture the current page.
2. Reduce the page to the first three sections only.
3. Load the core design stack: `impeccable`, then `product-design:get-context`, then `product-design:ideate`.
4. Before ideation, load the command context for `shape`, `extract`, `typeset`, `layout`, `colorize`, `adapt`, and `polish`.
5. Generate 3 to 5 visual directions in `9:16`.
6. Keep each direction distinct in layout, hierarchy, and mood.
7. Select the strongest direction.
8. When cloning a starter project, use `D:/Programy/client-projects/starter-kit` as the source and create the demo copy in `D:/Programy/client-projects/templates`.
9. Map the structure to starter-kit blocks and assets.
10. Turn the concept into a template inside `D:/Programy/client-projects/templates`.
11. Define the upsell as implementation, adjustments, or monthly care.

## Section Rule

Only design these first three sections at concept stage:

1. Hero
2. Services or process
3. Trust or contact

## Checklist

- Is the concept limited to three sections?
- Are the visual directions clearly different?
- Is the chosen direction simple enough to copy into a template?
- Is the upsell obvious after the concept is shown?
- Are all source files, target paths, and crop boxes explicitly named?
- Did the agent avoid inventing any extra assets or unnamed crops?

## Zero-Context Rule

Assume nothing is known unless the current prompt states it.

- No default source project unless named.
- No default target folder unless named.
- No extra asset extraction unless named.
- No "one more crop" unless named.
- No memory of prior assets unless the current prompt points to them.
- No substitute crop when the named asset is already handled.
- No continued asset work after the named asset is produced.
- Asset sources are only the user-provided source page or Image Gen output. No other source is allowed.

## Hard Stop Rule

When asset extraction is requested, the agent may only work on the asset explicitly named in the prompt.

- If the named asset is extracted, stop.
- If the asset is not named, stop and ask once.
- If the agent feels tempted to improve, tighten, or re-crop, that is a stop condition, not a permission.

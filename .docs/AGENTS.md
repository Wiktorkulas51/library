# UI Library Documentation Context

The repository contains a standalone component catalog. Documentation should describe reusable UI, variants, previews, tokens, accessibility, and migration into another project.

Do not add instructions for Starter Kit client onboarding, CMS editing, client handover, FTP deployment, forms, or production client QA here. Those workflows belong to the consuming project.

Canonical routes are `/`, `/components/`, and `/library/`. Keep documentation aligned with the current source tree and verify examples against the local build.
